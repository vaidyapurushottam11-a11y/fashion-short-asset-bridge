# Fashion Short Asset Bridge

Dedicated asset-transfer, assembly, QA, and release pipeline for No Face Style fashion reels.

Production rules:
- Vertical 9:16 output.
- Final reel is silent: no narration, music, SFX, or audio stream.
- Retention-first editing with fast opening cuts, deliberate source trimming, overlays, and loop-aware endings.
- Generated Magnific/Kling assets are transferred through GitHub Releases before assembly.

The production implementation lives on feature branches and is merged through pull requests.
